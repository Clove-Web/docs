Sandrone is a all-in-one Discord bot.

Sandrone does not have a database. It does not store anything about you, it does not track you, and there is nothing about you for anyone to sell. Commands are handled in memory and the result is thrown away.

The one exception is `/yt-dlp`: a download too big to attach to a Discord message is saved on the host and served from a link for a day, then deleted automatically. The file is the YouTube content itself, never anything about who asked for it. The [Privacy Policy](/projects/sandrone/privacy) covers this in full.
